# Home-Hunt-KH

### Find Your Perfect Place to Call Home.

## About the Project

Home-Hunt-KH is a rental property website designed to help people in Cambodia find suitable accommodation, including rooms, apartments, condominiums, and studios.

The platform aims to make the process of finding rental properties easier and more convenient, especially for students, workers, and people looking for affordable places to live.

## Features

- Property listings for rooms, apartments, condos, and studios.
- Search and filter properties by location, type, and price.
- Display rental prices and property information.
- View property images and details.
- Show property locations and rental conditions.
- Simple and user-friendly interface.

## Target Users

- Students looking for accommodation.
- Workers searching for rental properties.
- Individuals looking for apartments or studios.
- People searching for affordable housing in Cambodia.

## Technologies Used

- HTML5
- CSS3
- Little of Js2

## Design Concept

Home-Hunt-KH uses a clean, modern, and user-friendly design.

**Color Palette:**
- Primary: #B4490B
- Background: #FBEBDF
- Dark Accent: #8A3708

## Installation

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the index.html file using your browser or Live Server.

## Future Improvements

- User registration and login.
- Property owner accounts.
- Property submission system.
- Advanced search and filtering.
- Database integration.

## Project Purpose

This project was developed to practice web development skills, including website design, front-end development, and user interface creation.

It also aims to provide a convenient way for people in Cambodia to discover rental properties.
